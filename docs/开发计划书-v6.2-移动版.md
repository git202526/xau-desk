## 0. 结论先行

把现在的「价格卡 + 待办 + 内联 Tab 条 + 5 个面板」改成「**固定底部 6 Tab + 总览首页**」。核心动作只有四件：

1. 新增「总览」页，把现价、周期结论、仓位摘要、今天要处理压进一屏；
2. Tab 从页面中部挪到屏幕底部固定，5 个变 6 个，默认落总览；
3. 总览里的「我的仓位」整条可点，跳持仓页并高亮持仓汇总卡；
4. 其余页面内容不变，只做间距与视觉归位。

已确认的取舍（本期锁定，不再讨论）：

- 总览保留迷你走势图（效果稿里的 44px sparkline），不做增删；
- 配色维持深色金（`--bg:#0A101C` / `--gold:#D4A24C`），不换冷蓝灰；
- 执行位**不做**左滑减仓，仍是点击弹层。

## 1. 目标与验收底线

| 目标 | 可测的判定方式 |
|---|---|
| 手机上单手能完成一次决策 | 390×844 视口：底栏 6 项全在一拇指弧内，单次点击命中 |
| 打开就知道该不该动手 | 首屏无需滚动即可见：现价、方向结论、持仓盈亏、至少 2 条待办 |
| 页面不再"滚很久才找到 Tab" | 底栏 fixed，任意滚动位置可见，切页后内容回到顶部 |
| 从总览到持仓不超过 1 次点击 | 点「我的仓位」→ 落在持仓页顶部，持仓汇总卡高亮 1.2s |
| 不破坏 v6.1 已验收的能力 | 声音提醒、价格闪动、记一笔/减仓弹层、GitHub 同步、接入码全部回归通过 |

**硬性数值底线**

- 底栏高度 56px + `env(safe-area-inset-bottom)`，主内容 `padding-bottom ≥ 76px + safe-area`；
- 切 Tab 的视觉响应 < 100ms，不出现白屏或跳动；
- 390 / 360 / 430 / 768 / 1280 五个宽度下 `document.scrollWidth ≤ window.innerWidth`（无横向滚动）；
- 总览在 390×844 下 `scrollHeight ≤ 800px`（约一屏，允许 40px 以内溢出）。

## 2. 范围

### 2.1 本期做（P0）

1. 底部固定 Tab 栏：总览 / 结构 / 建仓 / 持仓 / 信号 / 设置，内联 SVG 图标 + 文字，active 金色指示。
2. 新增 `#panel-ov` 总览页：hero（现价、24H 区间、ATR、迷你走势）+ 判定卡 + 仓位条 + 今天要处理。
3. 仓位条 `.posbar`：持仓克重 / 均价 / 浮动盈亏三格 + 右侧 chevron，整条可点 → 跳持仓。
4. `gotoTab()` 重写：hash 同步、切页回顶、同 Tab 再点回顶、面板淡入。
5. 顶栏常驻小价格（见 4.4），解决"非总览页看不到现价"的退化。
6. Tab 角标：建仓页显示待买条数、持仓页显示待减仓条数。
7. iOS 键盘弹起时自动收起底栏，避免遮挡输入框。
8. 桌面端（≥768px）底栏居中悬浮，限宽 560px。

### 2.2 本期不做（明确排除）

| 不做 | 原因 |
|---|---|
| 左滑记减仓 | 用户确认暂不做，仍走点击弹层 |
| 横滑切 Tab | 与页面纵向滚动、长按选字冲突，收益低于成本 |
| 总览迷你走势图增删 | 用户确认维持效果稿现状 |
| 换配色 / 改字体 | 维持深色金 |
| 计算逻辑、止盈算法、事件雷达 | 本期零改动，避免回归面扩大 |
| 数据 schema、同步协议、接入码格式 | 零改动 |
| PWA / Service Worker / 离线包 | 超出本期，且 GitHub Pages 缓存策略需单独设计 |
| 买入记录折叠、筛选取舍 | 保持现状直出 |

## 3. 信息架构

### 3.1 Tab 地图

| Tab | key | 内容块（自上而下） | 数据来源 | 现有代码对应 |
|---|---|---|---|---|
| 总览 | `ov` | hero 价格卡 → 判定卡 → 仓位条 → 今天要处理 | `S.price` `S.struct` `holdStats()` `todoItems()` | 新增，复用现 hero / verdict / todo |
| 结构 | `struct` | 多周期共振 4 卡 → D1 判定依据 → 关键位列表 → 说明 | `S.struct` `S.levels` | `#panel-struct` 原样 |
| 建仓 | `plan` | 建仓基准摘要 → 弹药进度 → 6 档阶梯 → 说明 | `S.gears` `S.H_BASE` | `#panel-plan`（补摘要卡） |
| 持仓 | `pos` | 浮动盈亏 → 持仓汇总 4 格 → 止盈计划 → 执行位 → 买入记录 | `holdStats()` `S.takes` `S.buys` | `#panel-pos`（顺序微调） |
| 信号 | `sig` | 事件雷达 → 状态转移 | `S.events` `S.feed` | `#panel-sig` 原样 |
| 设置 | `set` | 参数 → 提醒 → 云端数据 | `S.cfg` `gh` | `#panel-set` 原样 |

### 3.2 动线

```
打开 → 总览（默认）
        ├─ 想看清结构 → 结构
        ├─ 该买了     → 建仓（角标提示待买）
        ├─ 该减了     → 持仓（从总览仓位条直达，或底栏）
        ├─ 想知道为什么 → 信号
        └─ 想改参数   → 设置
```

一句话：**买之前看建仓，买之后看持仓**，总览只负责"要不要动手"。

## 4. 交互规格

### 4.1 底栏

- 结构：`<nav class="tabbar" aria-label="主导航">` 内 6 个 `<button data-tab="...">`，每个含 21×21 SVG + 10px 文字。
- 固定：`position:fixed; bottom:0; left:0; right:0; z-index:60`，背景 `rgba(10,16,28,.92)` + `backdrop-filter:blur(18px)`，上边框 `1px solid var(--line)`。
- 安全区：`padding-bottom: env(safe-area-inset-bottom)`，`height: calc(56px + env(safe-area-inset-bottom))`。
- active：图标与文字变 `var(--gold)`，图标上移 1px，上方 18×2px 金色圆角指示条（`transition: .22s`）。
- 按压：`scale(.96)`，`-webkit-tap-highlight-color: transparent`（已全局）。
- 单项最小热区：宽度 ≥ 60px（6 项等分，390 宽下 65px），高度 56px，满足 44×44。

### 4.2 切页行为

| 场景 | 行为 |
|---|---|
| 首次打开，无 hash | 落 `ov`（总览） |
| 带 hash（如 `#pos`） | 落对应页，便于分享与刷新保持 |
| 点底栏 | `gotoTab(key)`：切 `.panel.on`、切 active、写 `location.hash`、`scrollTo(0,0)` |
| 再点当前 Tab | 仅回顶，不重绘 |
| 从总览仓位条进入持仓 | `gotoTab('pos')` 后给 `#posBox` 加 `.flash-card` 1.2s，提示来源 |
| 浏览器返回 | hash 变化触发 `hashchange` → 切页（不重复写 hash，防循环） |
| 键盘弹出（iOS） | `body.kb` 时底栏 `translateY(110%)`，键盘收起恢复 |

**性能约束**：`gotoTab` **不得调用 `saveCfg()`**。否则每点一次 Tab 都触发一次云端推送。

### 4.3 角标

- 位置：图标右上 6px 处，直径 15px，红底 `--up`，白字 9px，数字 > 9 显示 `9+`。
- 规则：到价待买数 → 挂「建仓」；止盈触发待减仓数 → 挂「持仓」；基准脱锚（fatal）→ 挂「设置」。
- 当前所在 Tab 不显示自己的角标。
- 数据来源：`todoItems()` 返回值按 `kind` 计数，**不额外计算**。

### 4.4 顶栏常驻价格（关键补充）

hero 移入总览后，持仓页/建仓页将看不到现价，而止盈位与建仓档位都必须对照现价。方案：

- 顶栏品牌区右侧、连接状态左侧，加一行 `#tpx`：`4072.40` + 小三角/色点，字号 13px `tabular-nums`，涨红跌绿。
- 点击 `#tpx` → `gotoTab('ov')`。
- 仅当当前 Tab ≠ `ov` 时显示（总览页已是大号价格，重复无意义），用 CSS `.tab-ov #tpx{display:none}` 控制。
- 更新仍由 `renderHero()` 一并写入，不新增定时器。

### 4.5 空态

| 场景 | 表现 |
|---|---|
| 无持仓（`holdStats().grams === 0`） | 仓位条三格显示 `—`，文案「还没建仓 · 去建仓页看看」，点击仍跳持仓（持仓页显示"记一笔"引导） |
| 无待办 | 「今天要处理」整块降权为 `.quiet`，灰字「当前无动作。计划已就位，到价会出现在这里。」（沿用现逻辑） |
| 未接云端 | 现有 `#ghWarn` 横幅保留在总览页顶部 |

| 元素 | 规格 |

## 6. 技术方案

### 6.1 DOM 迁移映射

| 现有位置 | 行号 | 去向 | 处理 |
|---|---|---|---|
| `<section class="hero">` | 388–414 | `#panel-ov` 内首位 | 整块移动，内部 id 全不变 |
| `<section class="sec">` 今天要处理 | 416–424 | `#panel-ov` 内末位 | 整块移动，`#todoBox` / `#todoList` 不变 |
| `<div class="tabs">` | 426–432 | 移到 `</div>`（wrap 结束）之后，改为 `<nav class="tabbar">` | 重写结构与样式，加「总览」项 |
| `#panel-struct` | 434–445 | 不动 | — |
| `#panel-plan` | 447–459 | 不动，顶部补一行摘要（可选 P1） | — |
| `#panel-pos` | 461–474 | 不动 | — |
| `#panel-sig` | 476–482 | 不动 | — |
| `#panel-set` | 484–~520 | 不动 | — |
| 新增 `#panel-ov` | — | 放在 `#panel-struct` 之前 | 含 hero + verdict + posbar + todo |

**顺序要求**：`#panel-ov` 必须是第一个 `.panel`，且默认带 `.on`，否则首屏空白。

### 6.2 新增与改造函数

| 函数 | 类型 | 说明 |
|---|---|---|
| `TABS` | 常量 | `['ov','struct','plan','pos','sig','set']`，顺序即底栏顺序 |
| `gotoTab(name, opts)` | 改造 | 参数校验 → 切 panel/active → 写 hash（`opts.silent` 时不写）→ 切页回顶；`opts.anchor` 时 rAF 后定位并高亮 |
| `initTabFromHash()` | 新增 | 读 `location.hash.slice(1)`，命中 `TABS` 则落该页，否则 `ov` |
| `bindTabbar()` | 新增 | 事件委托绑底栏点击；替代原 `bindUI` 里的 `.tabs button` 循环 |
| `todoItems()` | **抽取** | 从 `renderTodo()` 中把「构造 items 数组」整段抽出为纯函数，返回数组，不碰 DOM |
| `renderTodo()` | 改造 | 只负责把 `todoItems()` 结果渲染成 DOM |
| `renderBadges()` | 新增 | 读 `todoItems()` 计数，写三个角标元素的 `textContent` 与 `hidden` |
| `renderOv()` | 新增 | 只渲染 `.posbar` 三格（克重/均价/浮盈）与空态文案 |
| `renderHero()` | 微调 | 末尾追加写 `#tpx` 与 `body` 的 `.tab-ov` 类无关的价格文本 |
| `refreshAll()` | 改造 | 插入 `renderOv()` 与 `renderBadges()`，保持单向调用 |
| `onAction('setbase')` | **简化** | 现有手写 DOM 切换（清 className → 设 panel on）改为 `gotoTab('set', {anchor:'setBase'})`，去掉 6 行重复代码 |

**`renderOv()` 的输入约定**：只读 `S` 与 `holdStats()`，不得调用 `renderPos()` / `renderTodo()`。

### 6.3 调用依赖图（必须无环）

```
数据层   loadCfg / saveCfg / doPull / applyRemote / ghRead / ghWrite      （零改动）
   │
计算层   compute() → S.struct / S.gears / S.takes / S.H_BASE / S.events
   │
纯函数   todoItems()   holdStats()   computedKeep()   takeSummary()
   │
呈现层   renderHero  renderVerdict  renderOv  renderTodo  renderBadges
         renderStruct renderKL renderLadder renderPos renderBuys
         renderTake  renderEvents renderFeed renderStat
         ↑ 以上互不调用，只读数据
   │
调度层   refreshAll()  按固定顺序调用全部 render*
         gotoTab()     只切可见性 + hash + 滚动，不调任何 render*
```

铁律：`renderOv` 与 `renderPos` 之间、`renderTodo` 与 `renderBadges` 之间**只能共享 `todoItems()` / `holdStats()` 这类纯函数，不能互调**。

### 6.4 样式改造点

| 位置 | 改动 |
|---|---|
| `body`（L19–25） | `padding-bottom: calc(76px + env(safe-area-inset-bottom))`；≥768px 改 `calc(96px + ...)` |
| `.tabs`（L90–97） | 整段替换为 `.tabbar` 规则组（约 40 行），旧 `.tabs` 相关媒体查询一并删除 |
| `.panel`（L96–97） | `margin-top:13px` 改 `12px`；`#panel-ov` 单独 `margin-top:0` |
| 新增 `.posbar` | 68px 三格条 + chevron + 按压态 + `.flash-card` 高亮动画 |
| 新增 `.tabbar .badge` | 15px 红点数字 |
| 新增 `body.kb .tabbar` | `transform: translateY(110%)` |
| `@media(prefers-reduced-motion)` | 把 `.tabbar` 指示条位移纳入关闭范围 |
| `.topbar` | 加 `.tpx` 小价格样式 |

### 6.5 数据与同步影响

- **schema 零变更**：`S.cfg`、`S.buys`、`S.takes`、`S.feed` 字段不动，`pruneCfg` 不动；
- **不写本地业务数据**：总览与仓位条只读，不产生写操作，因此不会触发 `schedulePush`；
- **不持久化当前 Tab**：`S.tab` 仅内存态。刷新带 hash 才恢复，无 hash 回总览。理由：Tab 属于设备偏好，不该同步到云端形成冲突；
- **本地缓存 key 不变**（`LS_KEY` 只存令牌与只读快照），老用户升级不掉数据；
- **向后兼容**：v6.1 的 `data.json` 可被 v6.2 直接读取，回退时 v6.1 也能读回 v6.2 写入的数据（结构未变）。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| hero 移入面板后，`flashPrice` 在隐藏面板上执行 | 无报错但看不到闪动 | `#tpx` 顶栏价格同步闪（复用同一 old/new 值） |
| 固定底栏遮挡最后一行内容 | 底部按钮点不到 | `body` padding-bottom 用 `calc(76px + safe-area)`，≥768px 96px；发布前逐页滚到底截图核对 |
| iOS 键盘弹起时 fixed 底栏上浮压住输入框 | 无法输入 | `focusin/focusout` 切 `body.kb`；`visualViewport` resize 兜底 |
| 每次切 Tab 触发云端推送 | 无谓写入、易冲突 | `gotoTab` 不调 `saveCfg`；T11 用例守门 |
| hash 与 `hashchange` 互相触发死循环 | 页面卡死 | 写 hash 前判断 `location.hash` 是否已相等；`hashchange` 内用 `silent:true` |
| 面板 `display:none` → `block` 时图表尺寸计算为 0 | 关键位/阶梯布局错乱 | 现有渲染均为纯 DOM 拼接，无 canvas/SVG 尺寸依赖；若后续加图表，需在 `gotoTab` 后 rAF 重算 |
| 抽取 `todoItems()` 时漏改闭包变量 | 待办不显示 | 抽取后 `renderTodo` 只保留渲染段；用 T7 与手动到价场景各验一次 |
| GitHub Pages 缓存旧页 | 用户看到旧版 | `verTag` 改 `v6.2 · 10/29`；索引页 URL 追加 `?v=62` 分享；Pages 缓存通常 10 分钟内刷新 |

### 开发中定位并修复的两个真实缺陷

1. **底栏遮挡页面末尾**：`html,body{height:100%}` 让 body 高度锁定为视口，`padding-bottom` 被吞掉，最后一个按钮被底栏压住 6px。改为 `html{height:100%}` + `body{min-height:100%}`。
2. **止盈阶梯整块空白**：获利状态下「回本位」不进入 `above` 计算，没有 `dist` 字段，`t.dist.toFixed(1)` 抛错中断整个渲染。改为缺字段降级展示，不动任何计算公式。
