## 零、为什么必须排在 P20 之后

`allotSell` 的分摊基准是 `boughtOf(i)`。P20 之前它对账本模式返回的是「记录聚合」，P20 之后才是「标记净持」。如果先做 P21，反摊公式会在 P20 落地时整体失效，等于白写一遍。

## 一、批一：快照与反摊（核心）

### 1.1 `allotSell` 改成返回分摊快照

**位置**：`allotSell(gram, px)`，当前返回写入的档数 `hit`。

改法：

```js
// 返回 { lot: {"1":8,"2":12,...}, hit: 2 }，无可摊时返回 null
function allotSell(gram, px){
  // 前段不变：算 nets、sum、splitByGram
  // 中段不变：逐档写 sold / proceeds
  // 追加：把实际写入量记进 lot
  var lot = {}, hit = 0;
  for(...){
    if(addG > 0.05){ lot[String(k)] = Math.round(addG*10)/10; hit++; }
  }
  return hit ? { lot: lot, hit: hit } : null;

```

**兼容性**：现有调用点只有 `saveSell` 一处（另有 `__xt` 导出给测试用）。测试里若有断言返回值是数字，改为断言 `.hit`。

### 1.2 新增 `unallotSell(lot, gram)`

```js
/* 把一笔卖出的分摊退回去。
   lot 存在 → 精确退；lot 缺失 → 按当前各档 sold 占比近似退，总量精确。 */
function unallotSell(lot, gram){
  var n = gearCount(), marks = S.cfg.gearMarks || {};
  if(lot && typeof lot === "object"){
    Object.keys(lot).forEach(function(k){
      var idx = Number(k);
      if(!(idx >= 1 && idx <= n)) return;          // 档数变过，超界跳过
      var m = marks[String(idx)]; if(!m) return;
      var sold = Number(m.sold) || 0;
      var back = Math.min(sold, Number(lot[k]) || 0);
      var ratio = sold > 0 ? back / sold : 0;
      m.sold = Math.round((sold - back) * 10) / 10;
      m.proceeds = Math.round(((Number(m.proceeds)||0) * (1 - ratio)) * 100) / 100;
      if(m.sold <= 0.05){ m.sold = 0; }
    });
    return true;
  }
  // 近似路径：按 sold 占比退，最大余数法保证总量精确
  var total = 0, arr = [];
  for(var i = 1; i <= n; i++){
    var m2 = marks[String(i)];
    var s2 = m2 ? (Number(m2.sold)||0) : 0;
    arr.push(s2); total += s2;
  }
  if(!(total > 0)) return false;
  var q = Math.min(Number(gram)||0, total);
  var parts = splitByGram(q, arr);
  for(var j = 0; j < n; j++){
    if(!(parts[j] > 0.05)) continue;
    var mk = marks[String(j+1)]; if(!mk) continue;
    var s3 = Number(mk.sold)||0;
    var b3 = Math.min(s3, parts[j]);
    var r3 = s3 > 0 ? b3 / s3 : 0;
    mk.sold = Math.round((s3 - b3) * 10) / 10;
    mk.proceeds = Math.round(((Number(mk.proceeds)||0) * (1 - r3)) * 100) / 100;
    if(mk.sold <= 0.05) mk.sold = 0;
  }
  return true;
}
```

**注意**：`splitByGram` 的第二个参数是「各档的权重数组」。这里用 sold 本身当权重，得到的就是「按 sold 占比退」。

### 1.3 `saveSell` 新增分支

**位置**：`saveSell` 里 `if(S.editing){ ... } else { ... }` 两段。

```
新增分支：
  push 记录（先不带 allot）
  调 allotSell(gram, cnyToUsd(priceCny))
  若返回非空 → 记录.allot = r.lot
  若返回 null → 不加字段（该笔没有可摊的档）

编辑分支：
  找到旧记录 old
  若 old.allot 存在 → unallotSell(old.allot, old.gram)
  否则 → unallotSell(null, old.gram)          // 老记录走近似
  更新记录字段（gram / priceCny / time / note）
  重新 allotSell(新 gram, 新 px)
  写回 记录.allot（无则 delete）
```

**关键顺序**：必须先退旧、再摊新。反过来会双重累加。

### 1.4 `delBuy` 卖出分支

**位置**：`delBuy` 里 `if(isSell){ ... }` 段。

```
删除前：
  找到记录 old
  若 old.allot → unallotSell(old.allot, old.gram)
  否则 → unallotSell(null, old.gram)
  然后才 filter 掉记录
```

墓碑 `S.cfg.del` 逻辑不变。

### 1.5 批一测试

| # | 用例 | 断言 |
|---|---|---|
