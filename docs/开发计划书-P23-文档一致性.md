## 零、为什么文档要单独排一期

四期功能（P20/P21/P18/P19-2）全部落地后，`index.html` 是可信的，`CHANGELOG` 是可信的，**只有 README 不可信**：

| 全文 | 无「测试」章节 | 762 条用例、56 个文件、跑 15 分钟，新人（或三个月后的自己）不知道从哪跑 |

**本期只做文档，一行 JS 都不改**，并用测试把「文档与代码一致」这件事锁住，防止第三次漂移。

## 三、批三：把隐性约束写成显式文档

新增 `docs/约束-代码与DOM.md`，把散落在 CHANGELOG 里的踩坑点集中成一份「动手前必读」：

1. **`sanitizeHtml` 白名单**（`index.html:_ALLOW`）：只允许 `DIV SPAN BUTTON I S B STRONG EM` 八个标签；属性只允许 `class / value / data-* / title / aria-label`。因此：
   - 不能用 `<br>` 换行 → 用多个 `<div>` 或 `<span>` + CSS
   - 不能用 `<table>` → 用 flex/grid 的 div
   - 不能用 `id` → 用 `data-*` 定位（如 `data-rv="h"`）
   - 不能写 `style=""` → 全部走 class
2. **内联零外链**：不引 CDN / 字体 / 图表库；图标用内联 SVG path；图表用内联 SVG 手写
3. **单文件与体量**：当前 8915 行 / 388 KB（gzip 131 KB）。新增模块前先估算，超 500 KB 要拆期
4. **数据三层**：`S.cfg`（配置，落云端）/ `gearMarks`（档位执行，落云端）/ `buys+sells`（账本，落云端）。派生数据（复盘、回测）**不落盘**
5. **刷新单向**：交互 → 改数据 → `refreshAll()`，渲染函数之间不得互调

并在 README 增加「测试」章节：全量命令、单文件命令、耗时基线、已知 flaky 的处理方式。
