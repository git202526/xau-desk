# P10 · 双口径均价（锚定均价 / 选定档位试算均价）

> 版本：v6.23 · 2026-10-31
> 触发场景：设 8 档、目标均价锚定第 5 档，建仓页卡片只给「8 档均价 3777.3 ✓命中」。
> 用户原话：「我想要两个都计算出来，取名锚定均价和选定档位试算均价。点击对齐目标重新计算两个均价。
> 锚定均价的意思是计算 1 到选的那个锚定档位成交均价试算。」

---

## 1. 问题：一个数字回答不了两个问题

P9 之后「档位数」和「锚定档位」都能配，但均价卡只有一个数：

| 卡片上的数 | 回答的问题 |
|---|---|
| `8 档均价 3777.3` | 8 档全买满，均价落在哪 |

用户真正要决策的是两件事，混在一个数里：

1. **目标命中评估**——整条阶梯买满，均价离目标多远（现有那个数）。
2. **只打到第 k 档的均价**——如果价格只跌到锚定档就反弹，前 k 档的平均成本是多少。

所以拆成两个口径，各自对着同一个目标价 T 判命中。

## 2. 口径定义

设档位价 `p₁…pₙ`、计划克重 `plan₁…planₙ`（`planOf()`，含 P8 配额下沉后的派生量）：

```
锚定均价     = Σᵢ₌₁..k (planᵢ·pᵢ) / Σᵢ₌₁..k planᵢ      k = 锚定档位（自动时 = 权重重心最近档）
试算均价     = Σᵢ₌₁..n (planᵢ·pᵢ) / Σᵢ₌₁..n planᵢ      n = 当前档位数
```

- 权重**不重新归一化**：1..k 档就是这 k 档按计划买完的实际成交均价，剩余额度本来就没花出去。
- `k` 与档距反解用的是同一个 `anchorCenter()`，保证「锚定第 5 档」在价格层和均价层是同一个重心。
- 自动（`avgAnchor = 0`）→ `k = round(重心) + 1`；分布全压第 1 档 → `k = 1`，锚定均价退化为 `p₁`。
- `k = n` 时两个口径重合（锚定行照常显示，区间带上不再画第二条刻度）。

## 3. 一个必须讲清的事实：锚定均价**天然高于**目标

`target` 模式下目标价钉在**第 k 档的价**上（P9 口径：`d = (p₁ − T)/(k−1)` ⇒ `p_k = T`）。
于是 1..k−1 档全部比 T 贵，加权平均必然高于 T：

```
diff = 锚定均价 − T = d·((k−1) − ī_front)
```

这不是 bug，是「前段溢价」。卡片因此多一句解释（仅 target 方式且差值为正时出现）：

> 锚定均价高于目标属正常：目标价钉在第 5 档，前 4 档更贵，差额 63 美元就是前段溢价

例：H=4700、8 档、锚定 5、T=3900 → d=47.25、p₅=3900、试算均价 3902.8（命中）、锚定均价 3963.3（偏高 63.3）。

## 4. 实现位置

| 位置 | 改动 |
|---|---|
| `avgOfFront(prices, w, k)` | 新增：前 k 档加权均价（纯函数） |
| `anchorKOf(w)` | 新增：有效锚定档号（1 起），复用 `anchorCenter()` |
| `computeGears()` meta | 新增 `anchorK / avgAnchor / avgSel / diffSel / diffAnchor / hitSel / hitAnchor`；`avgAll/avg14/hit` 含义不变 |
| `renderAvgCardStruct()` | 标题改「选定档位试算 · n 档均价」，新增 `.a2` 行「锚定均价 · 第 1–k 档」+ 数值 + 判定；区间带加一条 `#D4A24C` 虚线刻度（与试算价差 ≤2 美元时不画） |
| `alignSpanToTarget()` | 重算后 toast 同时播报两个均价 |
| 设置页 `setAnchorLive` | 补「建仓页『锚定均价』按 1–k 档试算」 |
| 建仓页 note | 两个口径各一句，点明「对齐目标」两个数一起重算 |
| `__xt` | 暴露 `anchorKOf / avgOfFront` |

命中判定口径不变：`hit`（顶部那个 ✓/偏高/偏低）仍以试算均价 × 混合持仓成本为准，锚定行自带独立判定。

## 5. 验收

`tests/test_p10_dual_avg.py`（14 条）：

1. `anchorK` 跟随设置，`avgAnchor` == 1..k 手算值，`avgSel == avgAll`
2. 锚定均价 ∈ (p_k, p₁)，且 p_k = T
3. 锚定档位 5→3：截断更早、均价更高，p₃ = T
4. 自动锚定 == `round(wCenter)+1`
5. 锚定到最后一档 == 全档口径
6. 分布全压第 1 档 → k=1、均价 = p₁
7. 10 档 / 锚定 6 档不越界
8. 卡片同时出现「锚定均价」「第 1–5 档」「选定档位试算」「8 档均价」与两个数值
9. 两个判定互不影响（试算命中、锚定偏高）
10. 改锚定档位，卡片范围文案跟着变
11. 没设目标也出两个数，只是不判命中
12. 区间带锚定刻度：不重合时 1 条虚线，重合时 0 条
13. 点「对齐目标」两个数都重算，p_k 拉回目标
14. 设置页说明提到「锚定均价按 1–k 档试算」

全量：`505 passed`（P9 基线 491 + 14）。

## 6. 实施记录

- 2026-10-31：v6.23 落地。改动集中在 `computeGears()` 的 meta 与 `renderAvgCardStruct()`；
  引擎侧只加两个纯函数，没有触碰价格层与配额层。
- 曾想把锚定行也做成「命中/偏高」的强判定，实测发现 target 方式下它必然偏高（§3），
  于是保留判定但补了解释文案，避免用户误判为算法错误。
- 320px 窄屏实测：标题换行、`.a2` 行不溢出，卡片 `scrollWidth == clientWidth`。
