# P12 · 下沉标签标克重

> 版本：v6.25 · 2026-10-31
> 用户原话：「下沉的数字表示什么意思？换成下沉重量是否更直观？」

---

## 1. 它本来就是重量，只是没写单位

建仓页每一行右侧那枚胶囊：

```
+2.2g 下沉入     ← 这一档多出来 2.2 克
−1.5g 下沉出     ← 这一档让出去 1.5 克
```

数字来自 `rows[].shift = planOf()[i] − planBase()[i]`，两侧都是**克**，所以 `shift` 就是克重，
不存在百分比含义。原来只写 `+2.2 下沉入`，而同一行还有 `-17.4%`（跌幅）、`-2.0%`（偏离）、
`+0.0%`（涨跌），很容易把 2.2 读成占比 —— 这是唯一的毛病。

所以「换成下沉重量」不需要换，**标上 g 就行**。

## 2. 为什么不用百分比

| 口径 | 读者要回答的问题 | 适合吗 |
|---|---|---|
| 克重 `+2.2g` | 这一档还要买多少 | ✅ 下单价、下单量都用克 |
| 占比 `+9%` | 这一档在总仓里占多少 | ✗ 还要乘以总仓才知道买多少 |

P8 的语义是「钱跟着价格走」：某档买不到了，它的**待补克重**挪给别的档。
用户下一步动作是「按 +2.2g 挂单」，所以克重才是可执行的那个数。
弹药进度行已经用 `· 下沉 12.3g` 汇总，单位一致。

## 3. 怎么在不破坏文案契约的前提下加单位

P8 的 UI 测试断言胶囊 `textContent` 恰好是 `+16 下沉入` / `−16 下沉出`。
直接写 `+16g 下沉入` 会让 textContent 变化，等于改契约。做法：

```html
<span class="shift in" data-shift="第2档" title="…">
  <b>+16</b> 下沉入
</span>
```
```css
.shift b::after{content:"g";font-size:9px;margin-left:.5px;opacity:.7}
```

- 数字包进 `<b>`，`g` 由 `::after` 画 —— **伪元素不进 textContent**，老断言原样通过
- 视觉上 `g` 紧跟数字、字号小一号，读作「+16g 下沉入」
- `title` 补一句方向说明（「收到」/「让给」），并把它加进 `sanitizeHtml` 的属性白名单

## 4. 顺带补的说明

建仓页 note 加了一行：

> 档位上的「+2.2g 下沉入」是**克重**：已跌破的档买不到了，它的待补额度挪给现价附近的档，
> 这一档因此多出 2.2 克；「−1.5g 下沉出」是让出去的克重。点一下看全额明细。

点胶囊仍弹明细（`下沉 16g：第1档 16g → 第2档 +16g；价格回弹会自动恢复`）。
