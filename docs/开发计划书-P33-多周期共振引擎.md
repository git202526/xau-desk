`pivotsOf` 实现要点：

```js
/* 摆动点：左 3 右 3 严格极值。只扫最近 60 根，够取到最近两个高/低。
   用严格不等（> / <）避免平台期把同一价位重复计成两个摆点。 */
function pivotsOf(bars, i, L){
  L = L || 3;
  var hi = [], lo = [];
  for(var j = Math.max(L, i - 60); j <= i - L; j++){
    var isH = true, isL = true;
    for(var k = j - L; k <= j + L; k++){
      if(k === j) continue;
      if(bars[k].h >= bars[j].h) isH = false;
      if(bars[k].l <= bars[j].l) isL = false;
    }
    if(isH) hi.push({ p:bars[j].h, i:j });
    if(isL) lo.push({ p:bars[j].l, i:j });
  }
  return { hi:hi, lo:lo };
}
```

五条条件的 `{k, v, d}`：

| 序 | k | v | d |
|---|---|---|---|
| 1 | `价格站上 MA20 且 MA20 在 MA60 上` | `ma20 && ma60 && c>ma20 && ma20>ma60` | `现价 x / MA20 y / MA60 z` |
| 2 | `MA20 斜率 > 0.05 ATR` | `ma20p && maslope > 0.05*at` | `Δ ±a / 阈值 b` |
| 3 | `摆动高低点同步抬高` | `hi.length>=2 && lo.length>=2 && hi[-1]>hi[-2] && lo[-1]>lo[-2]` | `高点 h1→h2 · 低点 l1→l2` |
| 4 | `MACD 柱在零轴上方` | `m.hist > 0` | `柱 ±x · DIF y / DEA z` |
| 5 | `ADX≥25 且 +DI 占优` | `a.adx>=25 && a.pdi>a.mdi` | `ADX x · +DI y / −DI z` |

反向五条为同维镜像，`k` 用「且」「同步下移」「在零轴下方」「−DI 占优」等对称措辞。

**数据不足时的降级**：摆点不足 2 个时第 3 条 `v=false`、`d="摆点不足"`，不抛错（周线前期常见）。

```js
   dw.state !== "rg" && d4.state !== "rg" &&

```

置信度：

```js
var voters = [dw, d1, d4].filter(Boolean);
out.valid = voters.length;
out.same  = out.dir === "rg" ? 0 : voters.filter(function(v){ return v.state === out.dir; }).length;
var base = out.valid > 1 ? (out.same - 1) / (out.valid - 1) : 0;
var str  = Math.min(1, (d1 ? d1.adx.adx : 0) / 40);
out.confStr = Math.round(str * 100);
out.conf = out.dir === "rg" ? 0 : Math.round(Math.max(0, base) * 62 + str * 38);
if(out.valid < 2) out.conf = Math.min(out.conf, 40);
if(out.shape === "counter") out.conf = Math.min(out.conf, 60);
if(d1 && d1.adx.adx < 20) out.conf = Math.min(out.conf, 55);
```

`shape` 判定：

```js
if(!d1) out.shape = "nodata";
else if(d1.state === "rg") out.shape = "notrend";
else if(out.dir === "rg") out.shape = "veto";
else if(dw && dw.state !== "rg" && dw.state !== out.dir) out.shape = "counter";
else if(d4 && d4.state !== "rg" && d4.state !== out.dir) out.shape = "diverge";
else if(d4 && d4.state === out.dir) out.shape = "align";
else out.shape = "mixed";
```

## 五、风险与回滚

| 风险 | 处置 |
|---|---|
| 新条件在周线上摆点不足，长期 `v=false` | 第 3 条降级为 `d="摆点不足"`；周线本就只作背景，不影响方向 |
| 940 次判定超出 800ms | 先测；超了就 1d 保持 800、只加 4h |
| `dir` 语义变严导致 `takeProb` 的 +22% 加成变少 | 这是预期效果（震荡区不该加成）；若观感突变，把 `takeProb` 的 ±22%/−18% 改为 ±12%/−10% |
| 旧回溯结论被推翻 | CHANGELOG 注明「v7.0 起回溯序列不可与 v6.x 对比」；不保留双引擎开关 |
| 1h 卡从「方向」改「触发」引起困惑 | 四卡下方常驻一行说明；总览标签仍显示方向 |

**回滚**：`git revert` 单次提交即可；判定是纯派生，无数据迁移。
