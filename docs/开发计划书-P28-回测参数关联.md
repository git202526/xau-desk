# 开发计划书 · P28 回测与设置参数关联

> 目标版本 v6.45 · 对应 `docs/PRD-P28-回测参数关联.md`
> 一句话：让回测卡如实说明「用的是哪套参数」，并把量纲修对。

## 一、契约变化

### 1.1 `btBack(k, opts)`

| 项 | 旧 | 新 |
|---|---|---|
| `opts` 字段 | `{loop, realloc, fee}` | 增加 `height: "set"\|"then"` |
| `opts.realloc` | `false` 即关闭 | 保留；缺省值改为跟随 `cfg.realloc.on` |
| `opts.height` 缺省 | — | `"set"`（跟随设置高点） |
| `meta.budget` | `克 × $/oz`（错） | `克 ÷ 31.1035 × $/oz` |
| `meta.he` | 恒为 `btbHigh()` | 按 `height` 取值 |
| `meta` 新增 | — | `heSet`, `heThen`, `heightSrc`, `planGrams` |
| `stats.invest` | 量纲错 | `Σ(plan[i] / 31.1035 × pr[i])` |
| `stats.endMV` | 量纲错 | `净持仓克 / 31.1035 × 期末价` |
| `stats.realized` | 量纲错 | `Σ(卖出克 / 31.1035 × 卖出价) − 成本` |
| `peers.lump.invest` | `budget` | `budget`（不变，但数值修正） |

内部统一约定：**价格进入计算前先转 `$/g`**（`px / 31.1035`），此后所有「克 × 价格」都是美元。

```js
function btPxG(usdOz){ return Number(usdOz) / OZ_PER_G; }
```

### 1.2 计划来源

```js
// 旧
var plan = planOf();                    // 读实盘状态，双重下沉

// 新
var plan = planBase();                  // 纯权重分配，无状态
var eff = realloc ? reallocPlan(plan, { buyOf, dead, price: cl, prices: pr }) : plan;
```

`planBase()` 不读 `S.price` / `S.reallocDead`，回测与实盘彻底隔离。

### 1.3 新增 `btHeight(k, opts)`

```js
/* 返回 { he, src, setHe, thenHe, fell }
   src: "set" | "then" | "fallback"
   fell: 设置无高点时回退 then 的标记 */
```

## 三、用例清单（预计 22 条）

### 计算层（8 条）

| # | 断言 |
|---|---|
| `a1` | `budget == TOTAL / 31.1035 * 起点价`，误差 < 0.5% |
| `a2` | `invest == Σ(plan[i] / 31.1035 * pr[i])` |
| `a3` | `avgCost == invest / holdGram`，单位 `$/g` |
| `a4` | 无触发时 `endV == budget` |
| `a5` | `lumpEnd == budget / 起点价 * 期末价`（同量纲） |
| `a6` | `dcaEnd` 与 `lumpEnd` 同量级（比值 0.5~2） |
| `a7` | `endMV == 净持仓 / 31.1035 * 期末价` |
| `a8` | `realized` 在无卖出时 == 0 |

### 高点来源（5 条）

| # | 断言 |
|---|---|
| `h1` | 默认 `heightSrc == "set"` |
| `h2` | `set` 时 `meta.he == gearBase().he` |
| `h3` | `then` 时 `meta.he == btbHigh()`，且与 `set` 不同 |
| `h4` | 设置无高点 → `heightSrc == "fallback"`，`he == thenHe` |
| `h5` | 切回 `set` 后 `meta.he` 复原（无残留） |

### 隔离性（4 条）

| # | 断言 |
|---|---|
| `i1` | 回测前后 `S.reallocDead` 序列化相等 |
| `i2` | 设置开下沉、`realloc:false` → 结果与设置关时相同 |
| `i3` | 设置开下沉、`realloc:true` → 与手工 `reallocPlan(planBase())` 一致 |
| `i4` | 回测前后 `S.price` / `S.cfg.gearMarks` 不变 |

### UI（5 条）

| # | 断言 |
|---|---|
| `u1` | `#bbParam` 含高点、档数、档距、配额四项 |
| `u2` | 点击「当时」chip → `meta.he` 变为当时高点，chip 选中态切换 |
| `u3` | `#bbGears .bbg` 行数 == 档数，价格与 `r.gear[i].price` 逐行相等 |
| `u4` | 390 / 320 宽无横向溢出（`scrollWidth <= clientWidth + 1`） |
| `u5` | `set` 时出现「前视偏差」四字，`then` 时不出现 |

## 四、风险与预留

| 风险 | 处理 |
|---|---|
| 修量纲打红 b2/b3/b4 | 三条断言把错误量纲写死，属测试债。改断言时在 docstring 写明「旧：克×$/oz；新：克÷31.1035×$/oz」 |
