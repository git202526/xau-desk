## 一、先拆解两份任务的架构

把两份任务的指令逐节读完，它们不是"两份报告"，而是**同一套引擎的两个调用时点**。

### 1.2 22:00 任务（美盘前总览）

砍掉了 3/4/5/7/10/11 的推导过程，只保留：运行模式 → 数据 → 盘中边界 → 技术面判定 → 前 3 日 → 事件 → 建仓参数 → 买卖点止盈 → 输出 → 存档说明。


**这五个内核就是工作台要固化的东西。**

## 二、现有架构的四个结构性缺陷

| 缺陷 | 具体表现 | 后果 |
|---|---|---|
| **时点稀疏** | 一天只有 07:00、22:00 两个判断点 | 中间 15 小时的结构变化无人记录 |
| **判定不可复现** | 每次由模型重新推导，同一份数据两次结论可能不同 | 无法回测，无法归因，无法验证策略有效性 |
| **状态靠文本解析** | 存档是 Markdown 块，字段写在一段文字里 | 解析脆弱，一处格式错就丢历史 |
| **成本与延迟** | 每次运行要串行调用 2-9 个技能，整体预算 8 分钟 | 无法高频，无法交互 |

**工作台的定位不是"更好的报告"，而是把这套判定逻辑从「每次重新思考」变成「一次写死、持续运行」。**

## 三、产品定位

> **把两份报告里的判定逻辑，做成一个随时能算、能查、能回溯的计算器。**

| 对比项 | 定时任务 | 本工作台 |
|---|---|---|
| 触发 | 每天 2 次 | 打开即算，价格每 15 秒刷新 |
| 判定 | 模型推导 | 代码计算，同输入必同输出 |
| 状态 | Markdown 文本块 | 结构化字段 |
| 成本 | 每次多次技能调用 | 零调用，纯前端 |
| 部署 | 平台内 | 单文件，可 git push |

### 3.1 三个明确的产品边界（避免又做偏）

1. **点位全部用 XAU/USD（美元/盎司）**，不做人民币换算，不显示元/克
2. **「多空」只作为方向判定保留** —— 回答"D1 是上行还是下行"，用于决定趋势型买点成不成立
3. **交易动作只有买和减** —— 积存金不能做空，页面任何位置不出现「做空 / 空单 / 止损单 / 开空」

> 判定层说"方向偏空"，执行层说"不买，等分档"。这两句话不冲突，但要分开放。

## 四、独立运行的技术方案（已验证）

这是整个 PRD 最关键的部分。工作台不依赖任务，就必须自己拿到数据。

### 4.1 数据源实测结果

| 用途 | 来源 | 实测结果 |
|---|---|---|
| 实时价 XAU/USD | `api.gold-api.com/price/XAU` | ✅ CORS `*`，秒级，当前 4055.30 |
| 多周期 K 线 | `data-api.binance.vision/api/v3/klines` | ✅ CORS `*`，PAXG/USDT 400 根日线回溯至 2025-09 |
| 汇率 | 不需要 | 本版全部美元计价 |

### 4.2 用 PAXG 代替 XAU 做结构计算，行不行？

PAXG 是 1:1 锚定实物黄金的代币，实测基差：

```
PAXG 最新收盘 4056.55  ／  XAU 现货 4055.30  →  基差 +0.03%
```

**结论：可以作为结构代理，但必须做基差校正。**

校正方法：

```
scale = XAU现价 ÷ PAXG最新收盘        （每次刷新重算）
所有 K 线的 O/H/L/C × scale           （等比缩放）
```

等比缩放后，MA / ATR 同比例平移，RSI / MACD / ADX 数值不变，**所有点位直接落在 XAU 口径上**。

### 4.3 日线边界问题（必须处理）

| | 任务口径 | Binance 默认 |
|---|---|---|
| 日线切分 | 美东 17:00 收盘 | UTC 00:00 |

两者差 5–6 小时，直接用会导致日线结构偏移（尤其跨美盘尾段）。

**方案**：用 1h K 线自行合成美东交易日日线——

```
D1 一根 = 前一日 18:00 ET → 当日 17:00 ET（23 根 1h）
H4 一根 = 4 根 1h，锚定 18:00 ET 起算
```

代价是多一次 1h 数据请求（400 根 1h ≈ 16 天，够合成 16 根日线，不足以算 MA200）。

**折中**：日线用 Binance 原生 1d（400 根，够 MA200），仅在报告里标注「日线切分 UTC 00:00，与美东收盘口径差 5-6 小时」。H4/H1 用 4h/1h 原生。

> 这是精度与可算性的取舍。若你要求严格美东收盘口径，需要另找数据源（目前没有 CORS 友好的 XAU 日线源）。

### 4.4 断网与失败降级

```
主路径：实时价 + K 线 都拿到  → 正常判定，显示「实时」
降级 1：K 线拿到、实时价失败  → 用最后一根 K 线收盘价，标「延时」
降级 2：全部失败、有缓存      → 用 localStorage 上次数据，标「缓存 · HH:MM」，禁用信号
降级 3：全部失败且无缓存      → 只显示空态，不给任何结论
```

**任何降级状态都不允许出现"看起来正常但其实用的是旧数据"。**

## 五、判定引擎规格（开发依据）

这一节是代码要照着实现的东西，不是描述。

### 5.1 周期与指标

| 周期 | 数据 | 用途 |
|---|---|---|
| D1 | 1d × 400 | 主趋势、MA200、H_eff、关键位 |
| H4 | 4h × 250 | 次级趋势、共振 |
| H1 | 1h × 500 | 短期结构、买点 C 确认 |

指标：MA5/20/60/120/200、RSI(14)、MACD(12,26,9)、ADX(14)+DI±、ATR(14)、VWAP（日内）。

### 5.2 三态判定（单周期）

| 状态 | 条件（满足 ≥3 条） |
|---|---|
| **上行** | 收盘 > MA20；MA5 > MA20；MA20 斜率 > 0；近 20 根高点抬高；ADX ≥ 20 且 +DI > −DI |
| **下行** | 镜像 |
| **震荡** | 两者都不满足，或 ADX < 20 且均线纠缠 |

### 5.3 共振与置信度

```
resonance = 同向周期数 / 有效周期数
置信度 = round(同向数 / 3 × 60 + ADX强度分 × 40)
ADX强度分 = min(1, ADX_D1 / 40)
```

输出句式（与任务口径一致）：

> `D1 下行 · H4 下行 · H1 震荡，共振 2/3，置信 67，方向偏空`

### 5.4 关键位

- **摆动点**：左右各 5 根内的极值
- **斐波那契**：最近一段 20 根区间，回撤 23.6/38.2/50/61.8/78.6，延伸 127.2/161.8
- **枢轴**：经典 P=(H+L+C)/3，R1/S1 等
- **PL90 / PL180**：近 90 / 180 个交易日最高收盘

### 5.5 H_eff 与六档

```
H_eff 主基准 = 近 60 交易日最高收盘
降级条件（任一）：
  ① 现价低于 H_eff 超 20%
  ② H_eff 距今 > 45 个交易日，且其后 ≥2 次 ≥5% 反弹
  ③ 最低档（-18%）仍高于现价
降级基准 = max(近 20 日最高收盘, 最近摆动高点)
```

六档（可配置）：

| 档 | 回撤 | 克重 |
|---|---|---|
| 预警① | -10% | 0 |
| 预警② | -12% | 0 |
| 第1档 | -13% | 8 |
| 第2档 | -14% | 12 |
| 第3档 | -15% | 10 |
| 第4档 | -16% | 40 |
| 第5档 | -17% | 15 |
| 第6档 | -18% | 15 |

### 5.6 风控

| 闸 | 触发 | 影响范围 |
|---|---|---|
| TREND_GATE | D1 收盘 < MA200 | 只否掉趋势型买点，**不暂停分档** |
| F1 波动 | 单日跌幅 ≥5% 或 ≥3×ATR，或 3 日累计 ≥10% | 暂停新增分档，当日+次日 |
| F2 数据 | 价格/汇率/ K 线校验失败 | 当日全停 |
| F3 边界 | 回撤 ≤ -32% | 提示人工复核，不自动改档 |

### 5.7 基准失效（新增，任务里有漏洞）

**当现价低于第 6 档触发价、且一档都未买入 → 整轮作废，页面顶部红条提示重设基准。**

这是当前实际发生的情况：H_base 5311.60 → 六档 4621~4356 → 现价 4055，六档全部悬空，`trigger_add_gear_list` 为空。

任务里两版口径不一致（07:00 有"只降不升"，22:00 有"耗尽重设"），实际都没兜住。工作台把它做成**显式状态**。

## 六、功能设计（四模块）

### 模块一：状态总览

| 元素 | 内容 |
|---|---|
| 主价格 | XAU/USD 大字，涨跌点数与百分比 |
| 方向判定 | `D1 下行 · H4 下行 · H1 震荡`，共振 2/3，置信度，方向一句话 |
| 三周期色带 | 三个色块（红/绿/灰），一眼看共振 |
| 基准与回撤 | H_eff 数值 + 窗口 + 当前回撤% |
| 关键位 | 上方最近阻力 / 下方最近支撑，各显示距离 |
| 数据状态 | 实时 / 延时 N 分 / 缓存 · 时间 |

### 模块二：多周期与关键位

| 元素 | 内容 |
|---|---|
| 周期表 | D1/H4/H1 各自的：三态、MA20 位置、RSI、MACD、ADX |
| 共振条 | 横向三段条，同向用亮色，震荡用灰 |
| 关键位阶梯 | 从高到低：PL180 / PL90 / 斐波各档 / 枢轴 / 摆动点 / 当前价 |
| 关键位明细 | 每个位标注来源（斐波 61.8% / 枢轴 S1 / 前高）与距现价% |

### 模块三：建仓阶梯

| 元素 | 内容 |
|---|---|
| 六档阶梯 | 触发价（$/oz）、克重、状态（未到 / 刚到价 / 已跌破 / 已买入）、距现价% |
| 弹药进度 | 已买克重 / 总克重 |
| 基准失效横幅 | 六档全穿时置顶，带「重设基准」入口 |
| 买入确认 | 点档位 → 一键记入（写状态 + 时间），不改克重配置 |

### 模块四：信号与事件

| 元素 | 内容 |
|---|---|
| 事件雷达 | FOMC（内置官方日程）、非农（惯例推算）、表内事件 |
| 信号流 | 状态转移记录：方向翻转 / 档位触发 / 基准失效 / 熔断激活 |
| 每条带依据 | 例如「方向由震荡转下行：D1 收盘 4055 跌破 MA20 4120，ADX 26」 |
