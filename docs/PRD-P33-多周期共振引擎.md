## 一、问题

现行引擎（v6.65）在四个维度上都偏离了技术面判定的通行做法。以下数字均来自真实 K 线实测（PAXGUSDT，1d 800 根 ≈ 570 个可评估交易日，判定逻辑按 `judgeOne` 逐行复刻）。

### 1.1 十条条件不是十份证据

| 指标 | 实测 |
|---|---|
| `upN + dnN` 均值（满分 10） | **4.46** |
| 恰好互补（一侧 3、另一侧 2） | **58%** 的点 |
| 五条条件两两 φ 相关（最高） | **0.75**（收盘>MA20 ↔ MA5>MA20） |
| 主成分参与率（有效独立因子） | **2.35** |

五条里四条都是「价格 vs 均线」的单调变换，反向五条是正向的镜像（第 1–3 条完全互斥）。**加条数只会放大同一个观点。**

### 1.2 三态退化成两态

| 周期 | 上行 | 下行 | 震荡 |
|---|---|---|---|
| 1d | 52% | 40% | **8%** |
| 4h | 41% | 56% | 3% |
| 1h | 39% | 53% | 8% |

一个号称三态的判定，92% 的时间只输出方向。同时 **30%** 的「有方向」发生在 ADX<20 的震荡区。

### 1.3 周期权重与层级相反

| 周期 | 现权重 | 自身 20 根前瞻（up 态） | 胜率 |
|---|---|---|---|
| 日线 | 35% | **+1.99%** | 63% |
| 4h | 30% | −0.12% | 45% |
| 1h | 20% | −0.15% | 40% |

低周期合计 **50%**，而它们在各自时间尺度上没有区分度。四周期完全同向只占 23%（独立假设 12.4%），**四个周期约等于两个独立视角**。

### 1.4 置信度是两条不同东西的混合

`conf = |score|×62 + min(1, 日线ADX/40)×38`

- score = 0（多空完全对冲）时仍给 **34**，这 34 全部来自 ADX
- 只有日线一个周期有效时也能到 50
- 置信 70+ 的一档，20 日后均值反而 −0.60%

### 1.5 抖动与不可验证

| 现象 | 数值 |
|---|---|
| 方向切换 | 569 天 128 次，**平均 4.4 天一次** |
| 周线可回溯点 | 220 − 209 = **11 点** |
| 有效周期数不足 3 的交易日 | 51% |

根因之一：`judgeOne` 算了 `ma60` / `ma200` 却**没有任何地方读**，而 `BT_WARM = 209` 正是为 MA200 设的。

## 二、目标与非目标

### 2.1 目标

1. **条件集换成 5 条 / 4 维**，一维一票，杜绝同源刷票；有效独立因子提到 2.8 以上。
2. **周期分层**：日线定方向、周线定背景、4 小时定节奏、1 小时只做触发；低周期不再与日线等权。
3. **三态回归真实**：震荡占比从 8% 提到 30% 左右；ADX<20 不再给强方向。
4. **置信度拆成「方向置信」与「趋势强度」两个数**，对冲时归零。
5. **抖动减半**：方向切换从 4.4 天拉到 7 天量级。
6. **周线可验证**：预热 209 → 60，周线回溯 11 → 160 点。

### 2.2 非目标

| 不做 | 原因 |
|---|---|
| 加第 6、第 7 条条件 | 实测 6 条比 5 条更差：每信号质量下降、切换频率翻倍 |
| 加月线 / 15 分钟 | 四段阶梯（5×/6×/4×）已符合 4–6 倍惯例；月线对「几天到几周」的持仓无增量 |
| 接 DXY / 实际利率 / 银金比 | 需要新数据通道与额度，属 J 轮级别，单独立项 |
| 收益回测、准确率统计 | v6.49 已下线回测（前视偏差），本期不重开 |
| 改 `takeProb` 的公式 | 只跟随 `dir` 语义变化，公式本身不动 |

## 三、判定口径（核心）

### 3.1 单周期：5 条 / 4 维

| 维度 | 条件 | 判定式 | 为什么这样定 |
|---|---|---|---|
| 趋势 | 价格站上 MA20 且 MA20 在 MA60 上方 | `c > MA20 && MA20 > MA60` | 合并原 #1+#2（两者 φ=0.75，本就是同一信息）；用排列替代单对关系 |
| 趋势 | MA20 斜率 > 0.05 ATR | `MA20 − MA20[1] > 0.05 × ATR14` | 原 #3 缺量纲，0.3 美元与 30 美元的拐头同权 |
| 结构 | 摆动高低点同步抬高 | 最近两个摆动高点 HH **且** 最近两个摆动低点 HL（枢轴左右各 3 根） | 原 #4 只查高点，不符合道氏「HH+HL 成对」的定义 |
| 动量 | MACD 柱在零轴上方 | `DIF − DEA > 0` | 唯一的非均线维度；`macdOf()` 早已算好，零成本 |
| 强度 | ADX≥25 且 +DI 占优 | `ADX14 ≥ 25 && +DI > −DI` | 20 是震荡上沿，25 才是趋势确认 |

**反向五条**为同维镜像：`c<MA20 && MA20<MA60`、斜率 `< −0.05 ATR`、`LH && LL`、`柱 < 0`、`ADX≥25 && −DI>+DI`。

### 3.2 三态门槛（不变）

`upN ≥ 3 → 上行`；`dnN ≥ 3 → 下行`；否则 `震荡`。

实测分布：上行 42% / 下行 25% / **震荡 34%**。

### 3.3 周期角色与权重

| 周期 | 角色 | 权重 | 说明 |
|---|---|---|---|
| 周线 | 背景 | 0.10 | 只降级、不单独定方向 |
| 日线 | **定方向** | 0.50 | 唯一有正超额的周期 |
| 4h | 定节奏 | 0.40 | 回抽 / 延续，不否决日线 |
| 1h | 触发 | **0** | 不参与方向，只在结构页显示「触发 / 未触发」 |

`score = 0.10·w + 0.50·d + 0.40·h`（1h 恒为 0），保留作「合力分」内部字段，不再用于定方向。

### 3.4 方向裁决

```
dir = 日线状态                                  // 日线定方向
if (dir ≠ 震荡 且 周线有判定且反向 且 4h 有判定且反向)  dir = 震荡   // 二对一否决
```

- 日线震荡 → 直接震荡，不做任何补偿
- **4h 单独反向不否决**：那是「回调 / 反抽」，不是方向失效
- **周线单独反向也不否决**：只把置信压到 60，并在结构类型上标「逆周线」

### 3.5 置信度拆两段

```
valid  = 周/日/4h 中有判定的周期数（0–3）
same   = 与 dir 同向的票数（dir=震荡 时记 0）
base   = valid > 1 ? (same − 1) / (valid − 1) : 0      // 3/3→1，2/3→0.5，1/3→0
str    = min(1, 日线ADX / 40)

conf   = dir=震荡 ? 0 : round(base×62 + str×38)
if (valid < 2)          conf = min(conf, 40)     // 单周期最多 40
if (shape = 逆周线)      conf = min(conf, 60)
if (日线ADX < 20)        conf = min(conf, 55)     // 无趋势时的方向，最多中等
```

| 场景 | conf |
|---|---|
| 3/3 同向，ADX 36 | **96** |
| 2/3 同向（周线反向），ADX 36 | 65 → 封顶 **60** |
| 仅日线有效（4h 反向），ADX 36 | **34** |
| 3/3 同向，ADX 12 | 70 → 封顶 **55** |
| 方向震荡 | **0** |

置信为 0 时，进度条显示「方向未定」，右侧标签改为「强度 36」（单独展示 `str`），不写「置信 0」。

### 3.6 结构类型：6 态

按下列顺序判定，命中即停：

| # | shape | 条件 | 主文案 | 副文案 |
|---|---|---|---|---|
| 1 | `notrend` | 日线震荡 | 无趋势：日线 ADX {x} | 不做方向性判断，只执行回撤分档。 |
| 2 | `veto` | 日线与周线、4h **都**反向 | 方向作废：日线与中长周期相反 | 多空各半，只按回撤分档执行。 |
| 3 | `counter` | 仅周线反向 | 逆周线：日线{上行}、周线{下行} | {反弹/回调}级别，仓位按半档执行。 |
| 4 | `diverge` | 仅 4h 反向 | 日线多 →「回调中：日线向上，4 小时转弱」<br>日线空 →「反抽中：日线向下，4 小时转强」 | 多 →「等 4 小时重新转强再动手，不追空。」<br>空 →「反弹是修复不是反转，不追多。」 |
| 5 | `align` | 日线与 4h 同向，周线不反对 | 多头共振 / 空头共振 | {same}/3 同向 · 周线{确认/未反对} |
| 6 | `mixed` | 其余（4h 无判定等） | 方向待确认：日线{上行} | 4 小时无明确方向，按日线方向轻仓。 |

**旧版两个硬伤在本表里被修掉**：
- 旧版 `diverge` 排在 `notrend` 之前，ADX 12 也在讲「反转故事」→ 新表 `notrend` 最优先
- 旧版 `diverge` 不管大周期向上向下都写「4 小时在反抽」→ 新表按方向分写

五条逐条仍用 `{k, v, d}` 结构，`d` 给出具体数值：

| 条件 | d 示例 |

### 4.3 判定回溯

- 预热 `BT_WARM` 209 → **60**（MA60 需 60、摆点回看 39、ADX 28 取最大）

- 周线提示文案随点数改为「可回溯约 159 周」；1h 提示改为「最多 39 天」

### 4.4 总览页 · 四周期标签与结论

- 标签仍为 4 个、文字长度不增（**1 小时仍显示方向**，触发信息只在结构页），保证 320px 下不换行
- 结论按 §3.6 六态输出；`#cfNum` 在震荡态显示「强度 x」而不是「置信 0」

| 周期 | 根数 | 变更 | 预热 60 后可回溯 |

| 1w | 220 | 不变 | 160 |

## 七、验收标准

1. 日线 800 根时，五条条件两两 φ 最大 ≤ 0.70，有效独立因子 ≥ 2.8
2. 1d 真实数据下三态分布：震荡 ≥ 25%、上行 35–50%、下行 20–35%
3. 方向切换频率 ≤ 每 6 天一次（样本 ≥ 500 天）
4. `conf` 在 `dir=rg` 时恒为 0；3/3 同向且 ADX 36 时 ≥ 90
5. 结构类型：日线 rg 必定 `notrend`，不受周线/4h 影响
6. 回溯：1w 160 点、1d 740 点、4h 690 点、1h 940 点；周线提示「159 周」
7. 总览 4 个标签在 320px 下仍单行、无省略号
8. 全量测试通过；`file://` 双击打开控制台 0 错误
