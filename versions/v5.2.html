怎么配
① 私有仓库里放一个 data.json，内容填 {}
② GitHub → Settings → Developer settings → Fine-grained tokens → 新建
③ 权限只勾这个仓库的 Contents: Read and write，有效期建议 1 年
④ 把 github_pat_… 粘到上面，点「保存并开启同步」
令牌只存本机，不会写进 data.json，也不会传到网页里。
运行说明
· 独立运行：数据直接取自公开行情接口，不依赖任何定时任务
· 周期：周线 / 日线 / 4小时 / 1小时，日线回溯 800 根
· 全部点位以美元/盎司计算，不做人民币换算
· 数据存本机浏览器，可导出 JSON 迁移
· 不构成投资建议
